모델 설정

판단할 모델

같은 상태와 질문을 로컬 Laya 또는 Jev API에 전달합니다.

세 질문은 어떻게 답하나요?
행동 선택 · Choice
이름과 설명이 붙은 선택지들을 평가합니다. Laya는 가장 높은 확률의 선택지를 고릅니다.
점수 평가 · Score
설명된 각 단계의 확률로 가중평균을 계산합니다. 예: 0×10% + 1×20% + 2×70% = 1.6점.
확률 예측 · Noul
질문이 참일 확률을 0~1로 반환합니다.

세 질문은 같은 상태를 평가합니다. 위험도 응답이 자동으로 행동 선택에 들어가는 것은 아닙니다. 두 값을 연결하려면 보조 규칙이 필요합니다.

선택 확률, 응답의 확신도, 실제 기준 일치율을 구분해서 읽으세요. 확신도는 분포가 얼마나 한쪽에 모였는지를 나타내며 정답률이 아닙니다.

게임 인터페이스 Socket / Mod
게임이 제공하는 내부 상태를 읽고 행동 명령을 전달합니다. 게임에 마련한 소켓 또는 플러그인 연결을 사용합니다.
게임 플러그인 연결 Mod
게임에 설치한 모드가 상태를 읽어 보내고, 행동 명령을 게임 내부 기능으로 실행합니다. 각 게임에 맞는 모드 또는 브리지가 필요합니다.
화면·키보드·마우스 KBM
화면을 관찰하고 키보드·마우스로 조작합니다. 입력 미리보기에서는 실제 입력을 보내지 않습니다.
질문 유형
행동 선택(Choice)은 선택지 고르기, 점수 평가(Score)는 점수 매기기, 확률 예측(Noul)은 0~1 확률 예측입니다.
기준 행동 일치율
제어 모델의 원래 선택이 게임에 정의된 기준과 일치한 비율입니다. 실습용 규칙과 비교하는 값이며, 일반적인 모델 성능을 뜻하지 않습니다.
모델 응답 / 전체 처리
모델 응답은 판단 요청에 걸린 시간입니다. 전체 처리는 관찰, 판단, 추가 대기, 입력 등의 시간을 포함합니다.
목표 응답 시간
게임별로 정한 시간 기준입니다. 응답 성공 여부와 목표 시간 충족 여부는 따로 확인합니다.
오래된 관찰로 취소
최근 판단 기록 중, 관찰 유효 시간이 지났거나 게임 상태가 바뀌어 적용하지 않은 판단 수입니다.
보조 규칙 Policy
모델이 고른 행동을 게임별 규칙으로 보완합니다. 최종 행동은 모델의 원래 선택과 다를 수 있습니다.

실습 기록은 이 컴퓨터에 보관됩니다.
